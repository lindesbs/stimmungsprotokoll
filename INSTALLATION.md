# Installationsanleitung für das Stimmungsprotokoll

Das Stimmungsprotokoll wird wie eine App auf dem Gerät installiert, muss aber nicht aus einem App Store geladen werden. Sie benötigen lediglich die Webadresse, die Sie vom Anbieter erhalten haben.

## Vor der Installation

- Öffnen Sie die bereitgestellte **HTTPS-Adresse** auf dem Gerät, auf dem Sie das Protokoll verwenden möchten.
- Verwenden Sie möglichst dauerhaft denselben Browser.
- Beim ersten Öffnen ist eine Internetverbindung erforderlich.
- Ihre Einträge werden nur auf diesem Gerät und in diesem Browser gespeichert.

## Android mit Chrome

1. Öffnen Sie die Adresse in **Google Chrome**.
2. Tippen Sie rechts neben der Adressleiste auf das Menü **⋮**.
3. Wählen Sie **Zum Startbildschirm hinzufügen**.
4. Tippen Sie auf **Installieren**.
5. Bestätigen Sie die angezeigten Schritte.

Anschließend finden Sie das Symbol **Stimmung** wie andere Apps auf dem Startbildschirm beziehungsweise in der App-Übersicht.

## iPhone oder iPad mit Safari

1. Öffnen Sie die Adresse in **Safari**.
2. Tippen Sie auf **Teilen**. Je nach Safari-Ansicht befindet sich die Schaltfläche direkt in der Werkzeugleiste oder unter **Mehr**.
3. Scrollen Sie nach unten und wählen Sie **Zum Home-Bildschirm**.
4. Aktivieren Sie, falls angezeigt, **Als Web-App öffnen**.
5. Tippen Sie auf **Hinzufügen**.

Falls „Zum Home-Bildschirm“ fehlt, wählen Sie am Ende der Aktionsliste **Aktionen bearbeiten** und fügen den Eintrag hinzu.

## Windows, macOS oder Linux mit Chrome

1. Öffnen Sie die Adresse in **Google Chrome**.
2. Klicken Sie rechts in der Adressleiste auf das Installationssymbol, falls es angezeigt wird.
3. Alternativ öffnen Sie **⋮ → Streamen, speichern und teilen → Seite als App installieren**.
4. Bestätigen Sie mit **Installieren**.

Die Anwendung erscheint anschließend im Startmenü, App-Launcher oder Dock und öffnet sich in einem eigenen Fenster.

## Windows mit Microsoft Edge

1. Öffnen Sie die Adresse in **Microsoft Edge**.
2. Klicken Sie rechts in der Adressleiste auf **App verfügbar**.
3. Klicken Sie auf **Installieren**.
4. Wählen Sie bei Bedarf aus, ob die App an Startmenü oder Taskleiste angeheftet werden soll.

Installierte Web-Apps können in Edge unter `edge://apps` verwaltet werden.

## Mac mit Safari

Diese Möglichkeit steht ab macOS Sonoma 14 zur Verfügung.

1. Öffnen Sie die Adresse in **Safari**.
2. Wählen Sie **Ablage → Zum Dock hinzufügen**.
3. Bestätigen Sie mit **Hinzufügen**.

Die Web-App erscheint im Dock und im Programme-Ordner des Benutzeraccounts.

## Erste Verwendung und Offline-Test

1. Öffnen Sie die installierte App einmal mit Internetverbindung vollständig.
2. Legen Sie bei Bedarf einen Testeintrag an.
3. Schließen und öffnen Sie die App erneut.
4. Optional können Sie kurz den Flugmodus aktivieren und prüfen, ob die App weiterhin startet.
5. Löschen Sie den Testeintrag anschließend wieder.

Die Eingabe, lokale Auswertung und Anzeige vorhandener Daten funktionieren danach ohne Internetverbindung. Für Programmupdates wird gelegentlich eine Verbindung benötigt.

## Backup erstellen

1. Öffnen Sie die App.
2. Wählen Sie oben **Backup**.
3. Bewahren Sie die heruntergeladene JSON-Datei an einem geschützten Ort auf.

Die Datei ist nicht verschlüsselt und kann sensible Angaben enthalten. Sie sollte nicht ungeschützt per E-Mail oder Messenger versendet werden.

## Backup wiederherstellen

1. Öffnen Sie die App im gewünschten Browser.
2. Wählen Sie **Import**.
3. Wählen Sie die zuvor gespeicherte JSON-Datei.
4. Prüfen Sie die angezeigte Anzahl und bestätigen Sie den Import.

Der Import ersetzt die Einträge, die zu diesem Zeitpunkt in der App gespeichert sind.

## Gerät oder Browser wechseln

1. Erstellen Sie auf dem alten Gerät ein Backup.
2. Installieren Sie die PWA auf dem neuen Gerät.
3. Öffnen Sie dort **Import** und wählen Sie die Backup-Datei.

Es findet keine automatische Synchronisierung statt.

## Vor dem Deinstallieren

Erstellen Sie zuerst ein Backup. Beim Entfernen der App oder Löschen der Website-Daten können alle lokalen Einträge verloren gehen.

## Wenn „Installieren“ nicht erscheint

- Prüfen Sie, ob die Adresse mit `https://` beginnt.
- Laden Sie die Seite vollständig neu.
- Verlassen Sie den privaten beziehungsweise Inkognito-Modus.
- Aktualisieren Sie den Browser.
- Verwenden Sie auf iPhone und iPad Safari.
- Prüfen Sie, ob die Seite über die richtige, vollständige Adresse geöffnet wurde.

Die Anwendung kann auch ohne Installation als normale Website benutzt werden.

## Hilfe in einer Krise

Das Stimmungsprotokoll ersetzt keine medizinische oder therapeutische Hilfe. Über **Hilfe** in der App finden Sie die TelefonSeelsorge und weitere Anlaufstellen. Bei akuter Gefahr wählen Sie den Notruf **112**.
